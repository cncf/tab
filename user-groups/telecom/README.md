# Telecom User Group

The CNCF Telecom User Group represents the architectural and operational requirements of telecom networks and cloud native telecom applications. It connects telecom industry needs with CNCF projects, including needs related to multi-networking, configuration management, and lifecycle management across distributed edge locations.
